# CraftChain ⛏️

**Plan. Collaborate. Craft Smarter.**

CraftChain is a premium crafting management platform for Minecraft players. It specializes in **Recursive Dependency Resolution**—breaking down any item into its raw base materials across infinite sub-layers. Whether you're building a simple wooden pickaxe or a complex Redstone mega-base, CraftChain ensures you have every single log, ore, and gem accounted for before you swing your first tool.

## 🌟 Key Features

### 🔍 Recursive Dependency Engine
- **Breaking it Down**: Enter any item (e.g., *Enchanted Golden Apple*) and recursively see every sub-component required.
- **Raw Material Mapping**: Automatically calculates the total count of base resources needed (Logs, Iron Ore, etc.).

### 🤝 Strategic Collaboration
- **Team Roles**: Assign members as **Miners**, **Crafters**, or **Planners** to streamline workflow.
- **Invite System**: Generate secure invite codes to bring friends into your crafting project.
- **Activity Feed**: Track real-time contributions from your team.

### 🎮 Immersive "8-Bit Premium" Experience
- **Dynamic 3D Background**: A custom-coded 2D/3D particle system and wireframe cubes create a deep, immersive void.
- **Web Audio Sound Engine**: Authentic 8-bit sound effects for every action (clicking, success, joining team, completing items).
- **Responsive Aesthetics**: A sleek, dark-mode terminal layout optimized for both desktop and mobile.

### 🛡️ Secure Persistence
- **Firebase Authentication**: Full support for Secure Email/Password login and Google Sign-In.
- **Email Verification**: Mandatory verification flow to ensure user data integrity.
- **Persistent State**: Projects and settings are saved locally, ensuring zero data loss across refreshes.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run

1. **Clone the project**
   ```bash
   git clone <repo-url>
   cd joyful-assembly-main/frontend
   ```

2. **Install dependencies**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Launch the environment**
   ```bash
   npm run dev
   ```

4. **Production Build**
   ```bash
   npm run build
   # Generates a standalone index.html in /dist
   ```
